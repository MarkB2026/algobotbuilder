RSI Mean Reversion

BEEBOT

Your bot. Your rules.

Automated mean-reversion trading with local control.

BEEBOT scans for RSI mean-reversion opportunities, evaluates candidates against your configured trading plan and can execute trades through your broker.

Every trade is recorded in your own local database. You decide whether BEEBOT operates independently or connects to The Hive.

  • RSI mean-reversion strategy
  • Configurable trading plan and execution rules
  • Paper and live trading modes
  • Local trade history and analytics
  • Controlled position sizing and safety overrides
  • Optional Hive connectivity

WINDOWS INSTALLATION

Download. Install. Start using it.

BotScripts desktop tools are currently built for Windows 10 and Windows 11. Application data is stored locally unless a feature explicitly lets you choose to share data.

1

Download

Click Download for Windows on the tool you want. The download is the ready-to-install Windows application.

2

Run the installer

Open the downloaded EXE file and follow the installation prompts. Once installed, launch Dynamic Options Plotter from your desktop or Start menu.

3

Windows security message

Windows may display a security or SmartScreen message because BotScripts is independently distributed. Only continue if you downloaded the installer directly from BotScripts.org.

4

Launch the tool

Open the application from your Start menu or desktop shortcut. Your local application data remains on your computer.

Connections depend on the tool. Tracker applications use supported broker connections for the information they need. Trading applications such as BEEBOT may place orders only when configured by the user for trading execution.

ABOUT BOTSCRIPTS

Software ideas turned into working tools.

BotScripts is a home for practical software created through human direction and AI-assisted development. The goal is simple: build useful tools, keep them understandable and make them easy to run.

AI is part of the development process. Each application has its own defined purpose, rules and capabilities.

LOCAL-FIRST BY DESIGN

Your financial data does not need another cloud.

BotScripts desktop tools are designed to run locally. Trading data and application databases remain on your computer unless you explicitly use a feature that shares data, such as optionally contributing BEEBOT trade information to The Hive.
